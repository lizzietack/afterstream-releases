# Afterstream downloads

Installers for [Afterstream](https://afterstream.store), the Windows app that turns your streams into vertical clips for TikTok, YouTube Shorts and Reels.

**[Download the latest version](https://github.com/lizzietack/afterstream-releases/releases/latest/download/Afterstream-Setup.exe)** (Windows 10 or 11, 64-bit)

- Without a license key, Afterstream makes clips from 2 videos for free.
- Get the full version, guides and help at [afterstream.store](https://afterstream.store).
- Questions: support@afterstream.store

This repository only holds the installers. Afterstream's source code isn't published here.
